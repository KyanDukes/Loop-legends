# Loop Legends

Loop Legends is a Java-based music creation game that combines simple DAW-style tools with interactive game systems.

The project was built to experiment with creating a playable music-making environment where users can create beats, manage tracks, and interact with music systems directly inside the game.

## Features

- Piano roll system
- Track management
- Pattern generation
- Audio mixing
- Metronome system
- Keyboard and input handling
- Save data system
- Multiple game/application screens
- DAW-style workflow built in Java

## Technical Systems

Some of the main systems in the project include:

- `DAWMixer` - handles audio mixing functionality
- `DAWPatternGenerator` - manages pattern generation
- `DAWPianoRoll` - controls piano roll functionality
- `DAWTrackManager` - manages music tracks
- `DAWMetronome` - handles timing and tempo
- `SaveData` - manages saved project/game data

## Tech Stack

- Java
- LibGDX
- Object-Oriented Programming

## Project Status

This is an older version of Loop Legends and represents an earlier stage of the project.

A newer version of the game is currently being developed with improved systems, UI, and gameplay.
